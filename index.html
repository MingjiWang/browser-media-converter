Browser Media Converter (FFmpeg.wasm)

Convert audio/video locally in your browser (no backend). If something fails, the Worker logs will show why.

How to use
  1. Click Load Engine (first load may take time).
  2. Drop a file (audio or video).
  3. Choose output format + quality controls.
  4. Click Convert and download the result.

Some formats/codecs are experimental in FFmpeg.wasm builds. If one fails, try MP4/WebM for video, WAV/MP3/AAC/FLAC for audio.

              Advanced controls

              
Audio

              

                

                  
Bitrate (kbps)

                  
                  
Sets -b:a. Higher = bigger file, usually better quality (lossy).

                

                

                  
Sample rate (Hz)

                  
                  
Sets -ar. Common: 44100 / 48000.

                

                

                  
Channels

                  
                  
Sets -ac. Mono is smaller; Stereo preserves width.

                

              


              
Video

              

                

                  
FPS

                  
                  
Sets -r. Higher = smoother, larger, slower encode.

                

                

                  
Scale (w:-1)

                  
                  
Adds -vf scale=.... Use -1 to keep aspect.

                

                

                  
Codec

                  
                  
Sets -c:v. Some encoders may be missing in wasm builds.

                

                

                  
CRF

                  
                  
Quality target. Lower = better quality, bigger file. Typical 18–28.

                

              


              
GIF

              

                

                  
GIF FPS

                  
                  
GIF frame rate. Too high can make huge GIFs.

                

                

                  
GIF scale (w:-1)

                  
                  
Scale GIF for file size. -1 preserves aspect ratio.
